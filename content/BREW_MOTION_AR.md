# فيديو تحضير القهوة

الفيديو التعليمي رسم متجه أصلي بثلاث خطوات، وليس فيديو مولدًا بأدوات Google. ملفات النشر الجاهزة هي `public/media/brew-guide.mp4` و`brew-guide.gif` و`brew-guide-poster.webp`. يعرض الموقع MP4 مع زر إيقاف وتشغيل، ويستخدم صورة ثابتة عند تفضيل تقليل الحركة أو توفير البيانات. فتح GIF اختياري عبر رابط واضح للمستخدم.

لإعادة توليد الملفات فقط، شغّل `node scripts/generate-brew-motion.mjs` من جذر المشروع بعد تثبيت اعتماداته بـ `npm ci`. يحتاج سكربت التوليد إلى FFmpeg متاح في PATH ومتصفح Chromium في `/usr/bin/chromium`، بالإضافة إلى Playwright وSharp الموجودين في اعتمادات التطوير والمشروع. الصور الوسيطة تُحفظ في `.local/brew-motion-frames`، وهو مسار محلي لا يُنشر.

FFmpeg وChromium مطلوبان لإعادة توليد الوسائط فقط، ولا يحتاجهما تشغيل الموقع أو `npm run build`. الملفات المنشورة جاهزة مسبقًا.
